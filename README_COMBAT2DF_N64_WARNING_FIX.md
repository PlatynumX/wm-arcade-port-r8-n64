# Combat2DF N64 warning-clean fix

Combat2DF is based on Combat2DE and preserves the CZ attract-combat/runtime behavior.

The DD GitHub N64 build proved the host build and all four CTest suites pass, then failed under the stricter N64 GCC at `src/fix39/wm_fix39_runtime.c:912` with `-Werror=misleading-indentation`. The source was generated by `tools/fix39_execute_walk_source_patch.py` as two one-line `if` statements on one line.

DF changes only the generated C formatting to two braced `if` blocks. Conditions, assignments, and execution order are unchanged. A regression test prevents reintroduction of the exact warning-triggering form.
