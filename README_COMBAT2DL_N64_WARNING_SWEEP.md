# Combat2DL — N64 warning sweep

Combat2DK proved the converged N64 graph was compiling the Fix39 runtime and exposed two `-Werror=misleading-indentation` failures generated by the ANI_CODE completion patcher. Combat2DL rewrites those source-equivalent statements with explicit braces/newlines and adds a generated-tree regression scan before host/N64 builds. No combat semantics are intentionally changed.
