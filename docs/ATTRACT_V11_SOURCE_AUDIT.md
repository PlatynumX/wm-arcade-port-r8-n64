# ATTRACT.ASM V11 source audit

This is the source-facing checklist used by V11.  It exists to keep the N64
integration tied to named arcade services instead of replacing missing pieces
with approximations.

## Top-level loop

1. `show_hstd`
2. `DCS_LOGO`
3. `show_sports_logo`
4. `show_gameplay`
5. `creditscreen`
6. `show_title`
7. `show_gameplay`
8. `creditscreen`

10. `show_gen_tips`
11. `show_bios`
12. `show_bios_tips`

17. each eighth loop: `show_copyright`, `aama_message`, reset `AMODE_LOOPS`

## Designer hints

- `NUM_HINTS = 10`.
- `last_hint` increments before selection and wraps at 10.
- exact executable row order: 2, 4, 3, 9, 7, 5, 8, 1, 6, A.
- title setup: `osgemd_ascii`.
- body setup: `wsf10_ascii`.
- background: `hstd_mod`.
- bar/shadow: `MVEBAR_R`, `SHADOW01`.
- row carries exact tip art, mug art and `WGSF22_[1..0]` number art.
- final external transition: `OPEN_SCREEN_LINE` with A8=18, A9=6.
- then `SLEEP 80`, `wait_on_butn 15*TSEC`.

## General tips

- background/pixel wipe source: `hstd_mod`, `SET_UP_PIXEL_WIPE`.
- title: `osgemd_ascii`, exact string `gen_tip_mes`.
- rows: `ogmd10_ascii`, exact `gen_tip_table` order including blank rows.
- bar/shadow: `MVEBAR_R`, `SHADOW01`.
- `BLOW_0_TO_1`, `RESET_FROM_PIXEL_WIPE`.
- `SLEEP TSEC`, `wait_on_butn 10*TSEC`.
- kills `FLASH_PID` and `CYCPID` on exit.

## Operator message

- source checks first byte of each `CUSTOM_MESSAGE` row through `RC_BYTEI`.
- no nonzero row: immediate return.
- present message: run `dan_test` first.
- `dan_test` blocking sleeps are 2 + 1 + 32 source ticks.
- `dan_test` creates 32 bouncing `BALLD05A` objects and starts hscore color cycle.
- source message x=200, first y=50, y step=45, font `osgfont_t`.
- after rows: `SLEEP 2*60`, `wait_on_butn 6*TSEC`, `scrn_scaleout`, `WIPEOUT`.
- exact `CMESS_LINES`, `CMESS_LINE_SIZE`, CUSTOM_MESSAGE storage and operator
  page service remain external shared-operator dependencies.

## Time/date

- `READ_DIP`; DPTDON_B disabled -> immediate return.
- enables clock update and calls `_GetTime`.
- `SLEEPK 30` before presentation.
- source rows use `ogmd10_ascii`, `wsf14_ascii`, `wgsf24_ascii`.
- date strings use month + day + `, 19` + two-digit year.
- 99 is rejected by source's `CMPI 99/JRLT` year validation.
- time is converted to 12-hour display; source does not append AM/PM.
- `SLEEPK 25`, then button-poll loop up to `5*TSEC`.

## Copyright

- page one: lines 1..9 plus `SMWWF2`.

- source deletes page-one text objects before page two.
- page two: lines 10..19, settle, `wait_on_butn 3*TSEC`.
