Fix39 V12i build/verification checkpoint
=========================================

Scope
-----
Real-N64 V12h capture showed ranks/initials/crouton icons from the scrolling
Intercontinental and World HSTD pages being drawn over the fixed title banner.

Source basis
------------
HSTD.ASM::print_inter / print_beaten:
  MVEBAR_R  OZPOS = 0x1799
  SHADOW01  OZPOS = 0x1799

HSTD.ASM::draw_beaten_table_entry / rank helpers:
  row sprites/font objects use Z 0x1000..0x1003.

HSTD.ASM::MOVE_ALL_OBJS_UP:
  objects with OZPOS > 0x1798 are not assigned the -2 Y velocity.

Therefore the title banner/shadow remains fixed and in front of scrolling
entries. The V12h immediate N64 renderer drew the header first and rows second,
reversing that visual Z order.

V12i correction
---------------
- Split HSTD rendering into slate backdrop and fixed header overlay.
- Draw table rows between those two layers.
- Draw MVEBAR_R, SHADOW01 and the title after rows so they occlude scrolling
  objects exactly as the source Z values require.
- No scissor rectangle, guessed cutoff, coordinate change, timing change, or
  factory-data change was introduced.
- Retains V12h DMAWNZ palette-index-0 transparency and pindown-label-origin
  corrections.

Regression coverage
-------------------
- test_v12_patcher.py now rejects the old header-before-rows ordering and
  asserts the source Z-order rationale markers.
- Existing HSTD layout/timing/palette/hint pointer-hardening checks retained.
- fix39_attract_assets.py self-test retained.
- Structural patcher and Fix39 host smoke tests retained.

Hardware acceptance target
--------------------------
On both scrolling HSTD pages, ranks, initials, spears and defeated-wrestler
icons must scroll underneath the fixed red banner/title rather than through it.
The scroll cadence and 3-row grouping should remain unchanged from V12h.
