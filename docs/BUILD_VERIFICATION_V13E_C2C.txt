Source-backed reason
--------------------
DRONE.ASM drone_main reads each mode-list record as two signed bytes followed by
one LONG script-table pointer. Negative bytes skip mode comparison. A source
WORD of -1 is 0xffff, so both bytes are -1 regardless of byte ordering. The
parser therefore recognizes that exact terminal wildcard form and deliberately
refuses arbitrary packed WL mode values in this chunk.
