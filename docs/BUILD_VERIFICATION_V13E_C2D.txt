Source-backed reason
--------------------
The Williams/TMS source is bit-addressed and uses `$` as the assembler location
counter.  DRONE.ASM uses `(end_label-$)/32-1` to derive the maximum valid
index from the number of following 32-bit script pointers.  The C2 parser must
not try to feed `$` or source labels to Python's numeric evaluator.  C2d
recognizes only this exact source form and resolves it structurally: it counts
the actual LONG pointer records up to the named forward end label, then stores
`pointer_count - 1`, which is the value consumed before RNDRNG0 indexing.
