Fix39 V13e-c2e Sports PLATYNUMX WIMP-palette hardware correction

Hardware finding
----------------
C2d built and ran on N64 hardware. The large BE A MAN replacement was visible and
correct, proving SPORTLO8.IMG was live. The small diagonal PLATYNUMX replacement
was not perceptible.

Root cause
----------
The bundled SPORTBK.IMG is correct: its 98x109 MIDWAY WIMP object contains the
PLATYNUMX pixels and is associated with a 29-color SPORTBK palette whose first
source RGB555 words are:

  1108 1108 28CD 24AC 1C8A 1869 1468 0C25 0402

The stock N64 tools/sports_background_bundle.py does not read that WIMP palette.
By design it substitutes the original BGNDPAL.ASM SPORTBK palette. The replacement
pixel indices therefore survived, but were rendered with the wrong, very dark
colors.

Correction
----------
- preserve the C2d DRONE self-sized-list parser fix unchanged;
- preserve the working SPORTLO8.IMG / BE A MAN path unchanged;
- preserve SPORTBK/MIDWAY source dimensions, WIMP row padding, BMOD image order,
  and keyed/opaque palette behavior;
- copy tools/fix39_sports_background_bundle.py into the target repo;
- route only assets/fix39_sports_override/SPORTBK.IMG through that converter;
- read MIDWAY's exact 29-color palette and SPORTBK's exact 19-color palette from
  the authoritative round-tripped WIMP container;
- leave the stock converter/path unchanged when the Fix39 override is absent.

Acceptance
----------
- tests/test_sports_override.py verifies the replacement WIMP palette and script
  routing;
- Termux preflight runs scripts/prepare_sports_source_assets.sh against the real
  checkout and requires generated sports_background.c to contain the converted
  replacement prefix 2211 2211 519B 4959;
- package SHA manifest PASS;
- ZIP integrity PASS.

Expected hardware result
------------------------
Sports screen timing/movement remains unchanged; BE A MAN remains correct; the
diagonal PLATYNUMX logo is now visible in its authored purple/lavender palette.
