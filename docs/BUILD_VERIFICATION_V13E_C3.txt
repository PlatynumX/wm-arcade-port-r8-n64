WrestleMania Arcade N64 - Fix39 V13e-c3 verification
====================================================

Purpose
-------
C3 advances the direct DRONE.ASM port without turning on guessed AI behavior.
It generates executable DRONE script bodies and command-2 skill tables from the
historical source fetched by the Termux build.

C3 additions
------------
- tools/fix39_drone_scripts.py parses the active DRONE.ASM data/script body.
- Source script labels are decoded into the existing Stage25 VM op format.
- All command-2 percentage tables reached by those scripts are emitted as exact
  30-entry source tables and bound to script_skill_pct.
- resolve_script is bound to the generated source script registry.
- DRONE #dsdone semantics are corrected: the advanced script pointer is kept and
  execution yields for the tick; it does not clear/abort the script.
- Command-5 / EXGPC code-call seams fail closed while C4 services are unbound;
  the VM no longer silently advances past an unavailable source code call.

Still deliberately gated for C4
--------------------------------
- source plain rnd service (kept distinct from RNDRNG0)
- direct drone_seek service
- source command-5 / EXGPC code-call targets
- final live DRONE runtime activation

Build-time safety
-----------------
The package contains only a placeholder generated script header.  The Termux
helper fetches the historical source, regenerates the live script/skill header,
and refuses to continue unless real scripts and command-2 tables are produced.
The existing C2e Sports WIMP-palette override remains unchanged.

Local package tests
-------------------
- generator self-test
- C3 structural guards
- generated script compiler + VM semantics smoke
- Fix39 integration/namespace smoke
- prior C1/C2 and Sports regressions
