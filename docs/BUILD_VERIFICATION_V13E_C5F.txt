Fix39 V13e Chunk 5f verification
================================

Purpose
-------
Recover exact historical DRONE.ASM source windows for every reachable
command-5 / EXGPC executable seam before translating those bodies to C.
This pass does not pretend an untranslated TMS34010 body executed; runtime
service dispatch remains fail-closed unless a real handler is attached.

Release checks
--------------
1. sha256sum -c SHA256SUMS.txt
2. python tools/fix39_drone_bodies.py --self-test
3. python tests/test_v13e_chunk5f.py
4. all packaged tests/test_*.py
5. host C/VM smoke tests

The Termux/GitHub build additionally regenerates the service registry from the
fetched historical DRONE.ASM and requires a non-empty C5f body recovery report.
