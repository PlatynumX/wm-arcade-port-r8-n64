Fix39 v5 verification
=====================

Root cause addressed from the Android v4 host build:
- 16 direct-port ANIM.EQU enumerators used the same global C names as include/wm/anim.h.
- WM_ATTRACT_DCS_LOGO in the translated attract-cycle enum used the same global C name as include/wm/attract.h.
- Clang therefore emitted 17 enumerator redefinition errors in src/core/app.c.

Fix:
- direct-port mode flags are now WM_ARCADE_MODE_* (numeric values unchanged)
- translated attract screens are now WM_FIX39_ATTRACT_* (ordering/values unchanged)
- every source reference in the Fix39 bundle was updated consistently

Verification performed:
- all Fix39 C modules compile together with -Wall -Wextra -Wpedantic -Werror
- runtime smoke executable PASS
- synthetic app.c-style namespace probe declares the frontend WM_MODE_* and
  WM_ATTRACT_DCS_LOGO enums first, includes wm_fix39_runtime.h, and compiles with -Werror
- namespace probe PASS
